# Troubleshooting

## Arduino board not detected
- Check the USB cable
- Select the correct COM port in Arduino IDE
- Install the correct driver for the board

## Code upload fails
- Verify board type selected
- Ensure the serial port is correct
- Restart Arduino IDE and reconnect the board

## Sensor values are incorrect
- Check all wiring connections
- Confirm the sensor pin numbers match the code
- Use a stable power source
